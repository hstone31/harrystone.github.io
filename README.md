# harrystone.github.io

Personal academic website — plain HTML + CSS, no build step.

## Pages
| File | Page |
|---|---|
| `index.html` | About |
| `research.html` | Research |
| `teaching.html` | Teaching |
| `other.html` | Other |
| `cv.html` | CV (embeds `cv.pdf`) |
| `style.css` | Shared styling (colors at the top) |

## Deploy
1. Create a public repo on GitHub named exactly **`harrystone.github.io`** (the account must be `harrystone`).
2. Upload these files to the repo root (or `git push`).
3. Repo **Settings → Pages**: Source = *Deploy from a branch*, Branch = `main` / `(root)`.
4. The site goes live at https://harrystone.github.io within a minute or two.
